# 🔌 Слой API (Работа с серверами)

Здесь находятся клиенты, инстансы и функции для взаимодействия с удаленными серверами и базами данных.

### Что здесь должно быть:
- Инициализация клиента Supabase (`supabase.ts`).
- Настройка Axios/Fetch инстансов с базовыми URL и интерцепторами авторизации.
- Общие функции запросов (например, `fetchAnalytics()`), если они используются в разных сторах.

### ⚠️ Правило:
Компоненты из `components` или `features` не должны вызывать методы Supabase напрямую. Все запросы выполняются здесь или внутри Zustand-сторов.
