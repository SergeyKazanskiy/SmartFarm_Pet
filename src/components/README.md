# 🎨 UI-Kit и Общие Компоненты

Папка для «глупых» (stateless) атомарных компонентов, из которых собирается весь интерфейс приложения. 

### Что здесь должно быть:
- Папка `ui/` — кнопки, инпуты, чекбоксы, тултипы, базовые пустые модалки.
- Папка `layout/` — каркас сайта (Sidebar, Header, Footer).
- Все параметры (цвета, тени, анимации, размеры) должны быть завязаны на CSS-переменные (`var(--user-*)`) и формат OKLCH.

### ⚠️ Правило:
Компоненты здесь не содержат бизнес-логики, не делают запросов к серверу и не зависят от `stores` (за исключением глобального `themeStore` для стилей).
