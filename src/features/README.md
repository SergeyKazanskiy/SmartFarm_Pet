# 🧩 Функциональные Особенности (Features)

Бизнес-блоки приложения, которые несут конечную ценность для пользователя. Самостоятельные куски интерфейса.

### Что здесь должно быть:
- Формы авторизации (`auth/ui/LoginForm.tsx`).
- Функциональные модальные и диалоговые окна со своей логикой (например, `FeedbackModal`).
- Поп-апы настроек.

### ⚠️ Правило:
Каждая фича должна быть максимально изолированной. Если фичу нужно удалить, мы просто удаляем её папку, и приложение не должно сломаться в других местах.
