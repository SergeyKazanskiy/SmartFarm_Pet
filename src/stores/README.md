# 🧠 Центральное Хранилище (Zustand Stores)

«Мозг» всего приложения. Здесь сосредоточено управление состоянием, поведением и логикой данных.

### Что здесь должно быть:
- `themeStore.ts` — управление OKLCH цветами, звуками, поверхностями.
- `authStore.ts` — сессия пользователя, права, интеграция с Supabase Auth.
- `modalStore.ts` — глобальный контроль открытия/закрытия всех модалок.

### ⚠️ Правило:
Вся сложная логика, сайд-эффекты и мутации данных происходят в экшенах сторов, избавляя UI-компоненты от тяжелого кода.
