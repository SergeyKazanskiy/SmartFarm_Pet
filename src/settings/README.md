# ⚙️ Константы и Дефолтные Настройки

Декларативные неизменяемые данные, используемые как начальные состояния приложения.

### Что здесь должно быть:
- `theme.defaults.ts` — базовые пресеты тем (Light, Dark, Cyberpunk) с сырыми значениями hue, chroma, radius.
- `app.config.ts` — лимиты, системные константы, списки доступных языков.
