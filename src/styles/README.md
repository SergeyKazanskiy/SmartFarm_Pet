# 💄 Стили и Дизайн-Система

Точка сборки всех визуальных параметров приложения, работающая на связке CSS-переменных и OKLCH.

### Что здесь должно быть:
- `globals.css` — базовые стили Next.js и Tailwind.
- Подключение дизайн-токенов (динамические тени, объемность, скругления, коэффициенты анимаций).
- Маппинг кастомных свойств (`:root { --color-primary: oklch(...) }`).
